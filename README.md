# React 사이트 프로젝트

React + Vite 기반 사이트 제작 프로젝트입니다.

## 실행

PowerShell 터미널에서 실행하세요.

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시되는 Local 주소를 브라우저에서 열면 됩니다.
종료하려면 Ctrl + C를 누르세요.

## 주요 파일

- `src/App.jsx`: 메인 화면
- `src/App.css`: 메인 화면 스타일
- `src/index.css`: 공통 스타일
- `src/components/`: 공통 컴포넌트
- `public/images/`: 사이트 이미지

## 빌드

```powershell
npm.cmd run build
```
